# 本地唤醒、结束语音与空闲状态验证

日期：2026-11-09。基于主分支 `a847a68` 继续开发。本轮完成实现、自动化和离线模型验证；用户已确认真实语音验收稍后安排。

## 接入依据

继续使用迁自 STS 的火山 ASR/TTS、System One 和已锁定的 Pipecat `de8998789d5690073ddd1dafcec7268839af8153`。生产轮次仍由 Silero VAD、TranscriptionUserTurnStartStrategy 和默认 Smart Turn 驱动。

本轮在输入与 ASR 之间加入本地 KWS 音频入口，在 ASR 与 System One 之间加入识别入口控制。待唤醒时原始 PCM 只送本地 KWS，后续原生 VAD 收到静音以收束上一段状态；云端 ASR 无连接。准备和结束期间的迟到转写在识别入口丢弃。

唤醒只建立 ASR WebSocket、发送配置并等待服务成功响应；随后通过原有输出队列播放 200 毫秒叮声，收到实际 BotStoppedSpeakingFrame 后开放输入。结束后关闭 ASR、恢复 KWS，原生 worker、设备及当前上下文继续存续。准备期间取消则释放尚未完成的执行对象，重新准备本地待唤醒宿主。

语音附和与接管继续由 STS 的 System One 判意路径决定。回复关联随原生帧进入生成与播放路径，旧取消事件保持原回复的归属。

## 结束和计时

主窗口 `end_voice` 命令可取消准备、模型生成和播放。原生取消、结果提交完成后，使用锁定版本的 `_maybe_emit_user_turn_stopped(on_session_end=True, run_llm=False)` 提交残余正文，再由原生控制器 `_trigger_user_turn_stop` 结束轮次及清理策略缓存。这两处为版本相关的接入点；升级 Pipecat 时应运行准备、未完成语音、生成和播报取消测试。

模型只在语音激活期间获得内部 `end_voice` 工具，通过原生函数调用执行。工具轮次与最终收尾回答共享同一回复关联；结束动作等待最终回复完成且实际播放结束。新问题或真正接管会撤销旧结束意图，附和仍保留当前问答。

计时使用 asyncio 单调时钟。仅语音激活且活动集合为空时建立期限，默认 60 秒；收音、识别、判意、用户轮次、回复生成、函数调用和播放均有真实事件来源。活动重叠时继续暂停，全部处理完成后重置为完整等待时长。历史工具在阶段 10 接入后补测相应实际调用。

开发版配置来自 `.env`，默认 `VOICE_WAKE_WORD=你好小博`、`VOICE_WAKE_HOTKEY=Ctrl+\`、`VOICE_IDLE_TIMEOUT_SECONDS=60`，修改后重启生效。设置页与即时应用规则由阶段 14 完成。数据库沿用现有脚本，本轮无需结构变更。

## 离线模型验证

使用 Sherpa 官方中文模型 `sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01`、sherpa-onnx 1.13.8、pypinyin 0.55.0 和 ONNX Runtime 1.31.1。模型准备和来源见[资源说明](../../resources/README.md)。Windows 原生 DLL 显式使用 uv 环境的版本，KWS 和 Silero VAD 已在同一进程实际初始化成功。

使用 Windows Microsoft Huihui Desktop 离线生成 16 kHz、16 bit、单声道 WAV，通过文件逐帧送入实际模型。未启用真实麦克风或播放设备。

该结果验证默认词条转换和模型执行，真实说话效果及误唤醒率仍需实机验收。

## 自动化范围

`tests/test_wake_lifecycle.py` 覆盖组合键持续一秒、释放后重新计时、同次只触发一次、额外修饰键、非法组合与超时参数、活动重叠计时、收尾与接管关联，以及 KWS/识别入口的音频与转写流向。

`tests/test_voice.py` 使用本地 WebSocket/SSE/HTTP 服务和内存输入输出，执行实际 ASR、System One、模型、TTS 和原生聚合器。新增验证：

- 启动后 ASR 未连接；KWS 触发后等待 ASR 成功确认和叮声实际完成。
- 重复唤醒复用连接，准备期间取消后恢复本地待唤醒。
- 未完成发言、生成、播报期间结束，原生轮次复位，后续唤醒接续上下文。
- Agent 有收尾和无正文收尾两条路径；收尾被真实接管后继续交流。
- 待唤醒期间文字输入保持文字回复，下次语音仍正常播报。
- 空闲到期关闭 ASR，保留本地 worker。
- ASR WebSocket 握手失败后显示具体原因，释放语音资源，文字继续可用。

内存输出模拟有界设备写入；集成测试使用确定的短静音超时推进轮次，生产仍使用 Smart Turn。以上测试不连接真实云服务。
