# 阶段 12：主聊天界面与状态操作（I-12）

状态：未开始。前置阶段：09、11。

[返回总计划](../V1.0.0-implementation-plan.md) · [选定 UI](../../design/V1.0.0-ui.md)

## 目标

将基础聊天页面落实为选定主界面，使用真实消息和状态完成语音、文字、结束、重新开始与错误操作。

## 开始前核对

- 对照暖白效果图和 UI 文档，确认用户、助手身份行及气泡位置。
- 核对消息更新、状态、失败和快照事件的实际定义。
- 主界面操作调用已有运行时逻辑，保持与语音、悬浮入口一致。

## 子任务

- [ ] **12.01** 落实暖白底、浅杏色气泡、琥珀点缀与深暖灰文字。完成结果：主窗口有与已选效果图一致的实际渲染。

- [ ] **12.02** 完成侧栏导航、顶部名称/状态和底部输入布局。完成结果：对话、历史与设置可进入对应页面。

- [ ] **12.03** 用户头像/“我”和助手图标/“小博”分别独占身份行，气泡在下方。完成结果：右侧用户和左侧助手布局正确。

- [ ] **12.04** 接入流式消息、附和和已有回复片段。完成结果：更新到对应消息，片段正常显示，附和保存可见。

- [ ] **12.05** 顶部展示真实语音与处理状态，接入结束语音、重新开始。完成结果：准备和交互期间操作可用，行为来自后台。

- [ ] **12.06** 状态区域展示错误和恢复入口，失败文字旁接入重新发送。完成结果：恢复、重发与旧记录保留符合阶段 09。

- [ ] **12.07** 处理窗口隐藏、最小化、恢复时的快照与后续事件。完成结果：重新显示内容连续，后台工作继续。

- [ ] **12.08** 调整实际字号、间距和缩放下的可读性，核对键盘文字发送。完成结果：以真实内容覆盖较长消息和状态文字。

## 交付物

- 主聊天界面、状态区、输入与运行时操作接入。
- 正常、生成中、失败和恢复状态的实机截图。
- 实际 UI 参数及与选定效果图的对照记录。

## 验证步骤

1. 完成文字与语音交替交流，检查流式消息和状态。
2. 生成/播报期间发送新文字，检查旧片段与新回复。
3. 准备或播放期间结束语音，恢复待唤醒后继续。
4. 重新开始、读取旧历史、制造失败并重发或恢复，检查对应按钮和记录。
5. 隐藏、最小化再恢复，并在实际 Windows 缩放下核对布局。

以实际窗口和已有核心行为测试为主；只为新增的关键事件投影问题补测试。

## 完成条件

- [ ] 主界面视觉、身份行与气泡布局落实。
- [ ] 正常和错误操作均接入真实后台，消息和状态连续。
- [ ] 隐藏恢复和缩放表现有实测结果。

对应：T-01；AC-01、AC-09、AC-10、AC-17、AC-24、AC-34、AC-35、AC-37、AC-38 的主窗口部分。
