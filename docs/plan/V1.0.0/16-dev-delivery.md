## 开始前核对

- 确认交付代码与验证记录对应；Git 提交按用户明确指令执行。

## 交付物

- 开发运行文档、有效配置示例、资源准备说明和启动入口。
- 独立环境验证记录、最终验收清单和已知限制。
- 与实际选型、版本和功能一致的 PRD、架构及阶段完成记录。

## 验证步骤

1. 基于交付代码准备新的工作副本与环境，不使用相邻 STS 的虚拟环境和资源路径。
2. 按文档逐项准备依赖、模型与配置，完成手动和双击启动。
3. 验证文字问答、本地唤醒、语义接管、托盘隐藏和恢复。
4. 正常退出重启后继续对话，重新开始后查询旧原文。
5. 文档操作与实际不一致时修正文档或实现，并复测受影响步骤。

独立准备验证是本阶段重点；阶段 15 已通过且没有新变更影响的功能沿用已有记录。
