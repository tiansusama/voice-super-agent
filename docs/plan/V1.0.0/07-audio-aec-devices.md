# 阶段 07：外放 AEC 与默认设备生命周期（I-07）

状态：未开始。前置阶段：06。

[返回总计划](../V1.0.0-implementation-plan.md) · [音频架构依据](../../design/V1.0.0-architecture.md)

## 目标

让外放场景下的语义打断可用，并按产品规则处理 Windows 默认录音、播放设备变化，向界面提供真实音量。

## 开始前核对

- 记录实际麦克风、耳机、扬声器和 Windows 默认设备条件。
- 按候选库官方资料及本机安装结果核对 AEC 格式、执行上下文和参考输入要求。
- 阅读本地流 setup/start/cleanup 的实际实现，定位设备选择与重建位置。

## 子任务

- [ ] **07.01** 实测 AEC 候选，选择适合本项目的接入方式。完成结果：有耳机与外放对照和明确选择依据。

- [ ] **07.02** 确定设备格式、重采样、AEC 块处理和参考延迟衔接。完成结果：采集与参考采用一致约定，持续运行可用。

- [ ] **07.03** 将实际交付播放的 TTS 和提示音作为参考。完成结果：已生成但未播放音频不提前充当参考。

- [ ] **07.04** 在打断时协调播放队列、设备缓冲与参考流。完成结果：实际停止与参考变化对应，记录停止耗时。

- [ ] **07.05** 输出麦克风与实际播放两路音量。完成结果：外环与中央播报音波有独立数据来源。

- [ ] **07.06** 待唤醒时采用新默认设备，重建关联采集与 KWS。完成结果：切换后仍能本地唤醒。

- [ ] **07.07** 交互中旧设备可用时继续，按已确认时机采用新设备。完成结果：本轮不中途迁移，后续待唤醒/唤醒按规则运行。

- [ ] **07.08** 当前设备失效时报不可用，提供打开当前默认设备的重建操作。完成结果：资源释放范围与重开顺序明确，供阶段 09 接入主动恢复。

## 交付物

- 本地音频、AEC、播放参考和设备生命周期实现。
- 音量事件、设备失效事件和资源重建操作。
- AEC 参数、实际设备条件、回声与接管表现、停止播放耗时记录。

## 验证步骤

1. 分别戴耳机与外放，助手播报时保持安静，检查回声是否产生错误输入。
2. 播报中分别附和与真实接管，检查原生语义流程和实际停止效果。
3. 待唤醒时更换默认录音/播放设备，再唤醒并交流。
4. 交互中改变默认设置但保留旧设备，核对延后切换。
5. 使当前设备失效，检查错误与资源释放；阶段 09 再验证完整恢复按钮。

声学与设备用实际 Windows 环境验证；测试覆盖应用内音频参考与取消的必要逻辑。

## 完成条件

- [ ] 耳机与外放均有真实附和、接管及静默对照结果。
- [ ] 默认设备变化和设备失效处理符合 PRD。
- [ ] 两路音量与播放参考可用于后续界面，参数和限制有实测依据。

对应：T-06、T-12；AC-19、AC-36，提供 AC-32 的音量来源。性能目标在阶段 15 根据实测落实。
