# 阶段 03：真实文字对话与状态事件（I-03）

状态：未开始。前置阶段：02。

[返回总计划](../V1.0.0-implementation-plan.md) · [架构依据](../../design/V1.0.0-architecture.md)

## 目标

在桌面中完成真实流式文字交流，验证统一 Agent 的消息与控制路径，为语音和持久化提供已有运行基础。

## 开始前核对

- 阅读 STS 文字处理的打断、flush、追加输入顺序；按架构中的源码定位核对当前依赖。
- 核对 GUI 到后台命令链路、当前 DeepSeek 配置字段及真实模型接入条件。
- 明确前端展示消息与 Pipecat 原生模型消息的不同职责。

## 子任务

- [ ] **03.01** 装配文字执行配置，复用原生上下文、聚合器和 DeepSeek。完成结果：文字启动不依赖麦克风、ASR、System One 或 TTS 凭据。

- [ ] **03.02** 定义当前实际需要的用户消息、助手回复、输入来源与回复关联。完成结果：流式片段能更新到对应消息。

- [ ] **03.03** 将界面发送操作交给运行时，快速确认接收，异步推进模型生成。完成结果：新输入和控制命令不等待整段回复结束。

- [ ] **03.04** 将真实模型片段、完成与错误事件回传页面。完成结果：状态显示与生成过程一致。

- [ ] **03.05** 接入文字打断：先提交旧回复，再追加新输入和发起回答。完成结果：模型上下文顺序正确，旧生成不会继续覆盖新回复。

- [ ] **03.06** 支持窗口隐藏后继续生成，通过当前快照恢复界面。完成结果：重新显示时已有内容和后续片段连续。

- [ ] **03.07** 展示模型配置不足或请求失败原因。完成结果：界面仍能打开，后续设置和历史页面可接入。

## 交付物

- 可进行真实交流的基础聊天页面、文字对话装配与运行时发送操作。
- 消息和状态事件定义、上下文提交与展示事件接入位置记录。
- 文字接管的核心验证结果，供阶段 08 扩展到未完成语音。

## 验证步骤

1. 发送一个问题，观察首段文字、逐步更新与完成状态。
2. 围绕回答连续追问，核对前文能够被接续。
3. 生成中发送修正，再连续发送文字，检查旧回复提交与新输入顺序。
4. 隐藏主窗口，等待生成后重新显示，核对内容和状态。
5. 使用模型配置缺失及请求失败两种条件，检查可理解的错误反馈。

必要测试集中在原生提交顺序、新输入取消旧生成及消息关联，不逐字段复刻实现。

## 完成条件

- [ ] 真实文字对话与连续追问可用。
- [ ] 文字接管及时，旧生成不会推进当前新回复。
- [ ] 窗口重新显示能恢复当前对话，配置缺失时界面仍可访问。

对应：T-05、T-10；AC-05 的文字部分、AC-37 的初始能力装配。完整语音/文字状态保持在阶段 08 验证。
