# 阶段 06：本地唤醒、结束语音与空闲状态（I-06）

状态：实现与自动化验证已完成（2026-11-09）；默认词已用离线合成音频验证，真实麦克风、耳机、云服务与按键手感待验收。用户已确认本轮先完成实现与自动化。前置阶段：05，真实服务联调同样待验收。

## 目标

完成待唤醒、准备、连续语音交互和返回待唤醒的生命周期，支持唤醒词、组合键、主动结束与状态驱动超时。

## 开始前核对

- 依据阶段 05 的真实轮次、模型、分类和播放事件确定状态来源。
- 核对本地 KWS 候选、中文模型资源和词条转换要求；选定实现前实测默认词。
- 阅读 ASR 当前 setup 连接行为和 worker 默认空闲取消，明确本项目需要调整的接入位置。

## 子任务

- [x] **06.01** 落实运行时的待唤醒、准备、交互、不可用状态与活动记录。完成结果：状态有真实事件来源，可解释是否正在等待用户。

- [x] **06.02** 接入本地 KWS，准备资源和中文词条转换，验证“你好小博”。完成结果：待唤醒时本地检测可触发，云端 ASR 未连接。

- [x] **06.03** 实现默认 `Ctrl + \` 和可配置组合键的按住判断。完成结果：按住 1 秒触发，同次按住一次，松开后继续；激活时重复唤醒保持交互。

- [x] **06.04** 将 ASR 连接和 worker 生命周期分开，建立就绪反馈。完成结果：唤醒后准备，就绪后经统一播放路径发出“叮”声。

- [x] **06.05** 在主窗口接入“结束语音”，覆盖准备和播报。完成结果：取消相关准备、生成与播放，回待唤醒并保留上下文。

- [x] **06.06** 接入 Agent 结束意图的内部动作，关联收尾应答和实际播放完成。完成结果：Agent 决定收尾；旧收尾被新输入接管后不会稍后结束新交互。

- [x] **06.07** 实现默认 60 秒、正整数设置与单调时钟计时。完成结果：仅等待用户时计时，处理期间暂停，再次等待从设置时长开始。

- [x] **06.08** 返回待唤醒时关闭 ASR 并恢复本地检测，保持窗口与历史独立。完成结果：再次唤醒可接续原对话。

## 交付物

- 本地 KWS、组合键接入、ASR 按需连接和真实状态协调。
- 结束语音与内部结束动作、空闲计时及配置接入基础。
- 模型资源、词条支持范围、状态转换和计时验证结果。

## 验证步骤

1. 启动后分别用默认词和按键唤醒，听到提示后再发言。
2. 检查短按、持续按住、松开和激活后重复触发。
3. 在准备、生成和播报阶段点击结束，再次唤醒并关联追问。
4. 通过语音表达结束意图，覆盖有收尾应答及收尾被新输入接管的情况。
5. 用可控时钟检查首次等待、识别/生成/播报暂停及超时；历史工具接入后在阶段 10 补测读取期间计时。

KWS 和按键手感实机验证；计时与旧结束动作取消使用高价值状态测试。
