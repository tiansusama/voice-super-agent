# 阶段 13：悬浮收音球与单轮问答（I-13）

状态：未开始。前置阶段：09、10。

[返回总计划](../V1.0.0-implementation-plan.md) · [选定悬浮外观](../../design/V1.0.0-ui.md)

## 目标

主窗口不可见时，通过紧凑收音球和一轮问答框完成连续交互，正确处理附和、接管、手动隐藏与失败恢复。

## 开始前核对

- 复用阶段 02 已验证的透明区域、焦点、滚动和宿主能力。
- 核对真实麦克风/播放音量、语音状态、轮次、判意和错误事件。
- 阅读手动隐藏在本次激活期间保持、下一次唤醒重新处理的规则。

## 子任务

- [ ] **13.01** 落实右下方紧凑圆球、上方圆角问答框和任务栏间距。完成结果：比例与已选缩小稿一致，透明区域可用。

- [ ] **13.02** 外环由麦克风音量驱动弧长；中央按聆听、思考、读取、播报切换。完成结果：两路音量与状态各自对应，安静时收为短音柱。

- [ ] **13.03** 准备、识别时显示缓慢小幅音柱和短暂状态文字。完成结果：阶段结束收起文字，就绪提示仍由后台播放。

- [ ] **13.04** 用户开始本轮提问时出现问答框，通过背景与左右位置区分双方。完成结果：框内省去头像、姓名，只展示一轮。

- [ ] **13.05** 判意时保留当前问答，附和继续保留，确认接管后切换。完成结果：切换时显示已识别的新发言，旧历史仍在主界面和数据库。

- [ ] **13.06** 实现最大高度后的内部滚动、上滚暂停跟随、回到底部恢复。完成结果：新增回复不会夺走用户正在阅读的位置。

- [ ] **13.07** 按主窗口可见性、语音激活和手动隐藏标志管理显示。完成结果：最小化按不可见处理；手动隐藏后新发言不弹出，托盘可找回。

- [ ] **13.08** 左上结束、右上隐藏的悬停操作及指针可达区域。完成结果：移到按钮仍保持可点击；结束与隐藏效果分别正确。

- [ ] **13.09** 错误时保留问答并显示恢复；手动隐藏时由托盘反馈。完成结果：恢复成功回待唤醒并收起，下次唤醒按规则显示。

## 交付物

- 收音球、单轮问答、滚动与状态动效，以及桌面显示规则。
- 正常、判意、接管、隐藏、错误与恢复状态的实际窗口结果。
- 最终尺寸、动效参数和缩放检查记录。

## 验证步骤

1. 在其他应用输入时唤醒，检查悬浮出现不抢焦点，并显示真实收音变化。
2. 完成一轮，再附和、接管和提出新问题，检查内容替换时机。
3. 生成长回复，上滚阅读后接收新片段，再回到底部。
4. 隐藏组件后继续发言，通过托盘找回；主窗口显示和最小化时复核协作。
5. 分别点击结束与隐藏，检查准备、播放期间的行为。
6. 覆盖可见错误、手动隐藏后错误、恢复成功和下一次唤醒。

使用真实状态、音量及 Windows 窗口验证；事件投影和手动隐藏规则编写必要测试。

## 完成条件

- [ ] 一轮问答、判意/附和/接管和滚动规则可用。
- [ ] 音波、外环和临时提示来自真实状态与音量。
- [ ] 显示、隐藏、结束、恢复及不抢焦点均通过实机检查。
