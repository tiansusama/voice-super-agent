# 阶段 15：完整流程验收与性能测量（I-15）

状态：未开始。前置阶段：12、13、14。

[返回总计划](../V1.0.0-implementation-plan.md) · [完整验收场景](../../prd/V1.0.0.md)

## 目标

把已完成能力组合成可持续使用的开发版，以真实环境完成需求验收和性能测量，明确剩余问题与结果。

## 开始前核对

- 汇总各阶段产出、测试与实机记录，明确已通过项和待联动复核项。
- 记录 Windows、显示缩放、音频设备、网络、模型和运行配置。
- 核对 T-12 的待测指标，已有产品参数为按住 1 秒和默认空闲 60 秒。

## 子任务

- [ ] **15.01** 建立对应 AC-01～AC-39 的验收记录。完成结果：每项有条件、操作、预期、实际结果和问题关联。

- [ ] **15.02** 连续执行启动、唤醒、交流、附和、接管、结束与再次唤醒。完成结果：正常语音生命周期可连续使用。

- [ ] **15.03** 联动文字接管、迟到转写、重发与语音恢复。完成结果：没有旧回复被迟到结果重新推进或上下文错序。

- [ ] **15.04** 联动历史读取、取消、工作窗口裁剪、重新开始和重启。完成结果：原文、引用、当前范围与工具记录一致。

- [ ] **15.05** 覆盖主窗口显示/隐藏/最小化和悬浮手动隐藏/找回。完成结果：状态、焦点、错误入口和显示规则协作正确。

- [ ] **15.06** 分别在耳机与外放下验证静默、附和、接管、设备变化和恢复。完成结果：声学与设备结果带明确条件。

- [ ] **15.07** 测量唤醒、首文字/音频、分类和实际停播、回读、CPU/内存。完成结果：数据可以解释测量起止点和设备条件。

- [ ] **15.08** 依据结果与用户落实性能目标，修复影响验收的问题。完成结果：目标与现状分别记录，修复后复测相关项。

## 交付物

- 完整功能验收记录、设备与性能测量结果。
- 缺陷及修复关联、尚未解决问题和实际使用限制。
- 需要更新到 PRD 与架构的最终选型、参数和实测结论。

## 验证步骤

1. 运行当前核心测试集、前端类型检查和构建，处理实际报错。
2. 按完整演示流程核对正常路径和用户切换入口。
3. 以可控错误和真实设备操作验证失败、接管、恢复及迟到结果。
4. 按已记录条件测量指标，核对实际播放停止和 UI 状态是否一致。
5. 修复问题后复测受影响流程；无新变更影响的已通过项沿用记录。

AC-26 的最终独立环境准备由阶段 16 完成；其余需求在此汇总实际结果。数值目标以实测和确认结论为依据。
