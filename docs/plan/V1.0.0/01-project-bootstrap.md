## 目标

从本仓库准备独立环境，启动包含 React 页面和 Python 后台循环的桌面应用，为后续功能提供实际运行入口。

## 开始前核对

- 阅读 PRD 的 FR-14、T-11，以及架构的运行模型、依赖来源和目录建议。
- 核对当前仓库内容、Windows 开发环境、uv 和前端构建工具；确认 Python 3.12 候选的安装兼容性。
- 对照 STS 对应的 Pipecat Git 版本准备依赖，记录实际来源；需要的定制语音代码在阶段 05 迁入。

## 验证步骤

1. 从本仓库创建独立环境并安装依赖，检查安装来源和解释器位置。
2. 运行前端类型检查及构建，从桌面入口显示最小页面。
3. 关闭应用，检查 GUI 与后台循环均已结束。
4. 检查启动路径和依赖声明中是否引用相邻 STS 工作目录或其虚拟环境。

本阶段通过安装、构建和启动验证，不为目录存在或静态配置值编写镜像测试。
