# 阶段 11：有限工作窗口与重新开始（I-11）

状态：未开始。前置阶段：10。

[返回总计划](../V1.0.0-implementation-plan.md) · [工作窗口依据](../../design/V1.0.0-architecture.md)

## 目标

落实有限工作上下文和原文回读，支持重新开始后保留旧历史，并在重启后恢复当前工作范围。完成 P-04 的窗口与恢复验证。

## 开始前核对

- 核对当前模型实际配置、输入与输出限制，明确预算计算所需信息。
- 阅读普通请求、打断后请求、工具循环和原生提交的执行位置。
- 使用阶段 10 的稳定引用与读取能力；首版不生成模型滚动摘要。

## 子任务

- [ ] **11.01** 明确输入预算、输出余量、工具定义与工具结果余量。完成结果：预算和模型实际配置对应，有计算说明。

- [ ] **11.02** 实现系统指令、当前问题、近期完整轮次的装载。完成结果：近期关联内容优先保留，避免拆散必要关系。

- [ ] **11.03** 为更早内容保留有限原文预览、时间与稳定引用。完成结果：移出窗口正文仍可按需读回。

- [ ] **11.04** 在普通、打断后和工具循环请求中一致应用预算。完成结果：多轮读取不会因追加结果失去预算控制。

- [ ] **11.05** 按完整轮次及工具调用/结果关系整理模型消息。完成结果：不出现孤立工具调用或结果。

- [ ] **11.06** 实现重新开始：打断并提交旧回复，再更新展示起点与工作窗口。完成结果：新聊天区为空，旧历史和引用继续存在。

- [ ] **11.07** 保存和恢复当前工作范围，处理已取消工具及未完成回复。完成结果：重启保持最近一次重新开始后的范围。

- [ ] **11.08** 用长历史和窗口外主题验证模型原文回读。完成结果：回答能够引用实际读到的旧内容。

## 交付物

- 工作窗口装载、预算控制、重新开始和恢复实现。
- 预算参数来源、预览/引用策略及模型消息关系说明。
- 长历史、工具循环与重启恢复测试结果。

## 验证步骤

1. 构造超过当前工作窗口预算的历史，检查实际模型请求内容。
2. 连续调用工具读取长历史，核对每次请求的预算与消息关系。
3. 新输入打断工具或回答后继续交流，检查上下文有效性。
4. 选择重新开始，核对展示为空、模型从系统指令和后续输入继续。
5. 询问旧主题并回读，再退出重启，核对新工作范围与旧引用。

核心测试针对预算、完整消息关系、事务更新和恢复；真实模型验证窗口外回忆，不用生成摘要替代原文结果。

## 完成条件

- [ ] 所有相关模型请求受一致预算管理，历史正文持续保存。
- [ ] 窗口外内容能读回，工具消息保持完整关系。
- [ ] 重新开始与重启恢复符合产品规则。

对应：T-07、T-08、T-09；AC-13、AC-14、AC-15、AC-24、AC-27。
