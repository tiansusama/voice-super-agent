# 阶段 14：设置与历史记录页面（I-14）

状态：未开始。前置阶段：09、11。

[返回总计划](../V1.0.0-implementation-plan.md) · [配置和历史规则](../../prd/V1.0.0.md)

## 目标

完成日常交互设置、保存与生效反馈，以及保持当前上下文的历史浏览页面。

## 开始前核对

- 使用阶段 06 的唤醒、按键和超时接入，阶段 09 的能力状态，阶段 11 的工作窗口。
- 核对有效配置、已保存但待应用值的表示，以及设置失败时的处理。
- 历史页只读取记录，当前交流继续由运行时和工作窗口管理。

## 子任务

- [ ] **14.01** 布局唤醒词、组合键、正整数超时及保存结果。完成结果：默认“你好小博”、`Ctrl + \`、60 秒显示正确。

- [ ] **14.02** 接入中文词条支持范围和组合键录入/验证。完成结果：无法支持或应用的配置说明具体原因。

- [ ] **14.03** 落实按键保存后生效，超时使用新值且当前等待重新计时。完成结果：无需重启即可按规则使用。

- [ ] **14.04** 保存唤醒词并在下一次进入待唤醒时应用。完成结果：页面能说明已保存、当前生效或待应用状态。

- [ ] **14.05** 设置失败时保留该项旧有效值和运行行为。完成结果：保存结果与实际行为一致，重启后仍可解释。

- [ ] **14.06** 提供模型参数通过本地 `.env` 配置及重启生效的说明。完成结果：日常设置和服务配置入口清楚。

- [ ] **14.07** 历史按时间浏览、分页加载和查看完整原文。完成结果：长列表按需取得内容，旧问答和状态可读取。

- [ ] **14.08** 保持历史浏览与当前工作窗口独立，返回对话恢复当前展示。完成结果：浏览旧记录不改变模型上下文。

- [ ] **14.09** 在语音或模型不可用时检查页面访问和错误反馈。完成结果：设置及已有历史继续可访问。

## 交付物

- 设置页与配置校验、保存、生效反馈。
- 历史记录页、分页和完整原文查看。
- 有效值、待应用值、失败处理和重启后的验证结果。

## 验证步骤

1. 修改组合键，立即在其他应用中验证；检查仅报告能够可靠检测的冲突。
2. 等待用户时修改超时，再在处理中修改，分别检查计时行为。
3. 激活期间修改唤醒词，返回待唤醒后验证新词；重启核对保存结果。
4. 输入无效超时、不可支持的词和不可应用的按键，检查旧有效值保留。
5. 浏览并继续加载旧记录，打开原文后回到当前对话，继续关联追问。
6. 在能力不足条件下复核页面仍可打开。

核心测试覆盖设置应用时机与失败保留；分页和视觉通过真实页面检查。

## 完成条件

- [ ] 三项日常配置按既定时机生效，错误不会覆盖原有效配置。
- [ ] 历史浏览、分页和原文查看可用，当前上下文保持连续。
- [ ] 能力不足时页面可访问，配置和错误反馈清楚。
