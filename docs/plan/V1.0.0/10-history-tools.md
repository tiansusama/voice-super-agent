# 阶段 10：只读历史定位与原文回读（I-10）

状态（2026-11-10）：实现、自动化验证和真实 DeepSeek 回读验证已完成。真实麦克风下的回读接管随完整语音验收复核。前置阶段：04；可提前于完整语音功能收尾。结果见[验证记录](../../verification/stage-10.md)。

[返回总计划](../V1.0.0-implementation-plan.md) · [历史架构依据](../../design/V1.0.0-architecture.md)

## 目标

模型能够按主题、关键词或大致时间定位自身历史，读取原文和关联消息，长内容可续读；读取可被新输入接管。开始 P-04 验证。

## 开始前核对

- 核对保存的消息 ID、原文、来源、状态与回复关联，确认引用可对应实际记录。
- 阅读原生工具注册、取消和结果提交机制，采用已确认的 STS 取消流程。
- 依据真实数据和中文查询需求设计检索，核对短词与候选全文索引的限制。

## 子任务

- [x] **10.01** 定义历史定位与读取接口的参数、返回边界和续读表示。完成结果：返回量受控，调用方能继续展开原文。

- [x] **10.02** 实现关键词、时间范围和相关消息查询，覆盖短中文词。完成结果：结果带时间、来源、预览和稳定引用。

- [x] **10.03** 实现按引用读取正文及前后关联消息。完成结果：可从命中消息继续理解所属问答。

- [x] **10.04** 实现列表分页和长正文分段，明确偏移含义。完成结果：连续读取能衔接完整原文。

- [x] **10.05** 注册模型只读历史工具，范围限定为 Agent 自身历史。完成结果：模型通过工具定位和读取，而非一次装入全部历史。

- [x] **10.06** 沿用原生可打断工具机制，保存取消和已完成结果。完成结果：迟到旧结果不会推进旧回复。

- [x] **10.07** 生成真实读取状态，反馈未找到、失败和线索不足。完成结果：UI 状态与回复反映实际结果。

- [x] **10.08** 验证代表性历史规模的分页与查询，按结果落实必要索引。完成结果：较长查询不会长时间阻塞交互循环。

## 交付物

- 历史定位、分页读取、关联回读与原生工具接入。
- 工具参数和返回表示、查询与中文短词处理说明。
- 查询、续读、取消及真实模型回忆的验证记录。

## 验证步骤

1. 保存包含多个主题和时间的对话，分别按关键词、主题线索和时间询问。
2. 读取超过单次返回长度的原文，连续分页并核对衔接。
3. 查询短中文词，检查能定位已有相关内容。
4. 查询不存在内容、构造读取失败，观察真实反馈；线索不足时检查追问。
5. 读取中发送新文字，检查取消与迟到结果；阶段 08 接入后复核语音接管。
6. 阶段 06 接入后检查历史读取期间空闲计时暂停，阶段 05 后复核尚未播报时语音直接进入轮次。

核心测试覆盖查询和引用、分页边界、关联原文及原生取消；真实模型验证工具调用与回答依据。

## 完成条件

- [x] 长正文可续读，预览引用始终对应原文。
- [x] 新输入能接管读取，未找到与失败得到真实反馈。
