# Voice Super Agent

运行在 Windows 环境中的语音 Agent 项目，已完成独立开发启动、单实例、托盘常驻、窗口管理、DeepSeek 流式文字对话，以及 SQLite 对话保存和重启恢复。语音按实现计划继续接入。

开发启动与窗口联调见 [开发运行](docs/development.md)，版本范围见 [V1.0.0 PRD](docs/prd/V1.0.0.md)，进度见 [实现计划](docs/plan/V1.0.0-implementation-plan.md)。

## 项目目标

- 通过语音与 Agent 交互。
- 使用super-agent架构
- 操作电脑上的应用和界面。
- 控制项目中的控件。
